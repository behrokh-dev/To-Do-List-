# 📝 To-Do List

A modern, responsive, and feature-rich **To-Do List** application built with **HTML**, **Tailwind CSS**, and **Vanilla JavaScript**.

Designed with a clean UI and smooth user experience, this project helps users organize daily tasks efficiently while demonstrating practical DOM manipulation, Local Storage management, and interactive JavaScript features.

## ✨ Features

### 📌 Task Management
- ➕ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks with smooth animation
- ✅ Mark tasks as completed
- ⭐ Mark important/favorite tasks
- 📋 Display completed and active task states

### 🔍 Search & Filter
- 🔎 Search tasks instantly
- 🎯 Filter tasks by status
  - All
  - Active
  - Completed

### 🏷️ Categories
Organize tasks using categories such as:

- 💼 Work
- 🏠 Personal
- 📚 Study
- ✅ Health
Each task is displayed with its own category indicator.

### 📊 Task Counter
- Shows the total number of active tasks.
- Updates automatically whenever tasks are added, removed, or completed.

### 💾 Local Storage
All tasks are automatically saved in the browser using **Local Storage**, so your data remains available even after refreshing or reopening the page.

### 🎨 User Experience
- Beautiful modern UI
- Fully Responsive Design
- Smooth animations
- Clean typography
- Minimal design
- Scrollable task list
- Drag-to-scroll support
- Smooth delete animation

### 📱 Responsive
The application is fully responsive and optimized for all devices
